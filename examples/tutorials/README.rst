Tutorials
=========

End-to-end walkthroughs. Start with the first one and work through in order —
each builds on the last. All tutorials run against the ``cube`` baseline case
shipped at ``examples/cube/``; :func:`pyOFTools.clone_example` copies it to a
tmp directory so the original stays pristine.

Prerequisites:

- OpenFOAM v2406+ sourced (``source $FOAM_INST_DIR/etc/bashrc``).
- pybFoam and pyOFTools installed.
- The cube case mesh built once (``examples/cube/Allrun``).
